# SecureAsWise - Anka Sunucu Migrasyon Projesi

Bu depo, SecureAsWise A.Ş. iç kullanımına ait Anka sunucu migrasyon
projesinin kaynak dosyalarını içerir.

## Proje Durumu

⚠️ Bu proje artık aktif değildir. Tüm sunucular başarıyla
yeni altyapıya taşınmıştır.

## Dosya Yapısı

- `sunucu_kontrol.py` — Sunucu sağlık kontrolü scripti
- `osint_kaynaklar/`   — Eski alan adı kayıtları (arşiv amaçlı)

## İletişim

Sorularınız için Sistem Yönetimi birimine başvurunuz.
